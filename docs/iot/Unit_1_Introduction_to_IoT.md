## Section B — 8 Important long questions with concise answers

### Long Q1. Define IoT. Explain its main characteristics and advantages.
**PYQ — Mar 2023, Jan 2026**

**Definition:** IoT is a network of physical objects fitted with sensors, software and connectivity to collect and exchange data.

**Characteristics:** (1) connectivity, (2) sensing, (3) automation, (4) real-time monitoring, (5) device identification.

**Advantages:** saves time, reduces manual work, improves safety, supports remote control and enables data-based decisions. **Example:** Smart lights controlled by a mobile app.

### Long Q2. Explain the main components of an IoT ecosystem.
**PYQ — Mar 2023, Jan 2024, Dec 2024, Jan 2026**

1. **Sensors/devices:** collect real-world data.
2. **Actuators:** perform actions.
3. **Processor/controller:** executes logic.
4. **Connectivity:** transfers data using networks.
5. **Gateway:** connects different devices/protocols.
6. **Cloud/data storage:** stores and processes information.
7. **Application/user interface:** displays results and enables control.

**Flow:** Sensor → Controller/Gateway → Cloud/Application → Actuator.

*Note: January 2024 specifically asks for seven ecosystem components; classifications may vary by textbook.*

### Long Q3. What is an IoT gateway? Explain its roles.
**PYQ — Mar 2023, Jan 2024, Dec 2024, Jan 2026**

An **IoT gateway** connects sensors or local devices to other networks, applications or the cloud.

**Roles:** (1) protocol translation, (2) data collection, (3) filtering/aggregation, (4) local processing, (5) security and access control.

**Example:** A Zigbee smart-home gateway forwards sensor readings over Wi-Fi/Ethernet to a mobile application.

### Long Q4. Explain the main privacy and security challenges of IoT.
**PYQ — Mar 2023, Jan 2024, Dec 2024, Jan 2026**

**Challenges:** weak passwords, device hacking, insecure communication, outdated firmware, data leakage and unauthorized tracking.

**Protection:** strong authentication, encryption, regular updates, least-privilege access and secure network configuration.

**Example:** An unsecured camera may expose private video feeds.

### Long Q5. Define sensors and actuators. Differentiate between them.
**PYQ — Jan 2026, Dec 2024**

A **sensor** measures a physical condition and provides input data; an **actuator** changes the physical world as an output.

| Sensor | Actuator |
|---|---|
| Input component | Output component |
| Measures temperature/light/motion | Creates movement/sound/switching |
| Example: LDR | Example: servo motor |

**Flow:** Sensor → Arduino/controller → Actuator.

### Long Q6. What is edge computing in IoT?
**PYQ — Jan 2024**

**Edge computing** processes data near the sensor/device instead of sending every reading to a distant server.

**Benefits:** faster response, reduced internet traffic, lower latency and better operation during connectivity problems.

**Example:** A factory gateway detects abnormal vibration locally and immediately raises an alert.

### Long Q7. What are the technology drivers for IoT adoption?
**PYQ — Jan 2026**

Major drivers are: (1) inexpensive sensors and microcontrollers, (2) affordable wireless networks, (3) cloud storage and computing, (4) AI/data analytics, (5) low-power devices and batteries.

These technologies make connected systems practical, scalable and cost-effective.

### Long Q8. Explain sensing and actuation in an IoT system.
**PYQ — Jan 2026, Dec 2024**

**Sensing** means collecting physical data using sensors; **actuation** means performing an action using an actuator. A processor compares sensor readings with rules and sends a control signal.

**Example:** Temperature sensor → controller checks threshold → relay/motor driver → fan ON.

*Note: Exam papers ask the sensor–actuator difference; this is a combined revision formulation.*
