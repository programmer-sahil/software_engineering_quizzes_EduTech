## Cautions
- Several MCQs in the original papers have imprecise wording, duplicate plausible answers or outdated terminology. The unit files favor clearly solvable items; any material nuance appears in a note.
- The “Arduino IDE is written in Java” question refers to the **classic Arduino IDE 1.x** application. Arduino sketches use **C/C++**, and IDE 2.x uses a different software architecture.
- Past-paper recurrence does not guarantee future exam selection.
