## Section B — 7 Important long questions with concise answers

### Long Q1. Explain Future Factory concepts in Industrial IoT.
**PYQ — Jan 2026**

A **Future Factory** (smart factory) uses connected sensors, automation, robots and data analysis to improve production.

**Features:** real-time monitoring, predictive maintenance, connected machines, automation and improved quality.

**Benefits:** less downtime, higher efficiency, reduced costs and better safety.

**Example:** Vibration sensors warn workers before a factory motor fails.

### Long Q2. What is Brownfield IoT? Explain with an example.
**PYQ — Jan 2026**

**Brownfield IoT** adds sensors, connectivity and analytics to existing industrial machines without replacing the entire facility.

**Steps:** retrofit sensor → connect gateway → collect readings → monitor/alert.

**Advantages:** lower initial cost and longer machine life. **Challenges:** compatibility and cybersecurity.

**Example:** An old motor gets a vibration sensor to predict faults.

### Long Q3. What are smart objects? Explain their components.
**PYQ — Dec 2024**

A **smart object** is a physical object with sensing, processing and communication capabilities.

**Components:** sensor, processor, communication interface, power supply and optional actuator.

**Features:** identification, sensing, connectivity and autonomous responses.

**Examples:** smart thermostat and smart electricity meter.

### Long Q4. Explain IoT-A and Hydra. Differentiate between them.
**PYQ — Dec 2024**

**IoT-A** is an IoT research initiative that proposed an **Architectural Reference Model (ARM)** with common concepts for interoperable IoT design.

**Hydra** is a service-oriented middleware framework that connects heterogeneous networked devices.

| IoT-A | Hydra |
|---|---|
| Reference architecture/model | Middleware implementation framework |
| Guides system design | Supports device/service integration |

Both target interoperability.

### Long Q5. Explain common IoT applications, including smart cities and smart homes.
**PYQ — Mar 2023, Jan 2024, Dec 2024, Jan 2026**

**Applications:** (1) smart homes—lights, security and energy control; (2) smart cities—traffic and waste monitoring; (3) agriculture—automatic irrigation; (4) healthcare—wearable monitoring; (5) industry—machine condition monitoring.

**Benefits:** efficiency, remote monitoring, safety and resource savings.

### Long Q6. How does Industry 4.0 benefit industries? What challenges does it face?
**PYQ — Jan 2024**

**Industry 4.0** integrates IoT, automation, analytics and connected manufacturing.

**Benefits:** real-time visibility, quality improvement, predictive maintenance and flexible production.

**Challenges:** cybersecurity, high integration cost, skills gaps, legacy equipment and unreliable connectivity.

### Long Q7. What are IoT platforms and middleware? Explain their uses.
**Practice — Not verified PYQ**

An **IoT platform** manages device connections, data, security and dashboards. **Middleware** provides shared software services between diverse devices and applications.

**Functions:** device registration, data collection, protocol translation, access control and analytics integration.

**Examples:** AWS IoT Core (platform), Eclipse Kura (edge middleware).
