# PHASE 04 — Redesign the Landing Page

Using Phase 03 tokens/components, rebuild the homepage into a clean, beautiful student-first landing page. **Keep existing academic data untouched**.

Structure:
1. **Hero above the fold** — small eyebrow `DIPLOMA STUDY HUB`, clear headline such as `Your smarter way to prepare for semester exams`, one concise support sentence, strong `Start Learning` primary CTA and `Practice MCQs` secondary CTA. Use realistic claims, not '99.99%' guarantees.
2. **Right-side visual on desktop** — an original floating stack of study cards built with real UI: `IoT • Unit 5`, study-progress sample marked `Preview`, MCQ answer sample marked `Demo`, cheat sheet preview. No fake scores or misleading mock performance; decorative preview can show generic neutral states. On mobile stack cards below headline.
3. **Quick actions** — `Continue studying` (only with real stored progress), `Explore Subjects`, `Practice MCQs`, `PYQ Practice`, `Cheat Sheets`, `Watch Reels`. If no progress, show `Choose a subject` instead.
4. **Subject spotlight** — real active IoT card + locked Software Engineering teaser; derive subject counts/metadata from registry.
5. **How it works** — Choose subject → Select unit → Learn + practice → Review mistakes. Use 4 crisp steps.
6. **Content discovery** — featured authentic cheat sheets/PYQs/reels only when they exist; otherwise attractive transparent placeholders and `Coming soon` states.
7. **Credibility/mentor** — keep existing photos/captions, show in neat gallery or editorial profile. Do not enhance photos by altering identifiable people; do not invent students taught, qualifications or employer details.
8. **Career/admissions/services** — separate from exam flows, concise copy and correct contact buttons, no repeated banners.
9. **Footer** — subject map, contact, social links, useful site links and optional policy links only if those pages exist.

Interaction/visual criteria: spacious, elegant, subtle animated gradient/light orbs, tasteful depth/hover, scroll reveal only when it helps and reduced-motion alternatives. Visual polish must not slow first load; no autoplay media. Clear focus states and accessible contrast.

**Acceptance:** hero legible in < 1 mobile viewport where practical, both CTAs work, no dead links or repeated marketing paragraphs, no fabricated sample content presented as real, existing content preserved. Record screenshots/checks. No deploy.
